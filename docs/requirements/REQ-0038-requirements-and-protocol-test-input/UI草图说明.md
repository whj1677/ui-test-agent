## 页面与主要决策

顶层结构为“项目列表 → 项目工作台 → 用例/执行详情”。当前项目名称始终可见，项目概览集中呈现资料、前后端用例和最近选定批次；资料、用例、协议、绑定、脚本、批次和报告证据均归属项目。统计和操作明确当前项目、类型、批次或筛选范围；切换项目清空原选中集合，不混用旧结果或协议。数据归属同时在服务端核对，不能只靠页面过滤。项目复制、跨项目报表与隐式资料共享不在本轮范围。

| 页面 | 用户主要操作 | 状态边界 |
| --- | --- | --- |
| 01 资料与范围 | 统一上传PRD/MRD，可一并附协议和原型；采用版本、状态及范围；确认模型文字/图片使用范围 | 主输入PRD/MRD，附件按内容角色记录，不再需求/协议二选一；读取与授权分开 |
| 02 规则核对 | 查看原文位置、重复要求和冲突；继续无冲突部分 | 不按文件名决定优先级；协议只有格式时不补造业务预期；受影响用例单独待确认。 |
| 03 用例审阅 | 前端、后端分组审阅；查看步骤、预期、测试数据与来源 | 业务依据不足须澄清；协议未绑定与用例未确认分别显示；不编字段/错误码 |
| 04 确认入库与分别导出 | 两组分别确认入库，分别导出前端/后端Excel或JSON，接相应自动化 | 不混类，不把待绑定或已导出当执行通过；同一需求保留跨端关联 |
| 协议与绑定 | 选择已确认后端用例版本，上传或选择协议快照，逐步核对命令、字段、业务断言及缺项 | 纯技术映射形成绑定版本；业务冲突形成新候选用例版本；部分映射不能标整条可运行，旧导出不变 |
| 用例库与自动化 | 切换 UI/后端，选择已有用例或本次入库来源，查看脚本生成/修订/重生成、单条/选中/项目运行、版本与证据 | 可以直接进入，不依赖前四页；合成脚本版本明确标识，实际协议和执行支持待提供；没有真实生成或执行。 |
| 执行结果列表 | 按类型/批次查看用例列表、统计、异常筛选/分组、预期与实际摘要；点击详情看完整步骤，选中集合批量反馈修订或复跑 | 汇总范围显式标注；失败、阻塞、未执行分开；分组不确认根因；每条结果和历史保持，修订不放宽原断言 |

“测试设计”从 PRD/MRD 统一分析，结合可一并提供的协议/原型，形成前端和后端两组人工用例。用户已同意：没有协议但业务依据充分时，可设计、确认和导出后端业务用例，自动化状态为“待协议绑定”；缺少业务预期或存在冲突时仍需核对，不由模型补造。已有确认用例可直接使用共享自动化流程，无需重新上传需求；两种用例来源不混算，批次明确实际范围。

后补协议按原编号、步骤和预期逐项映射。绑定关联项目、用例版本及内容摘要、协议快照及摘要、步骤映射和执行器；纯技术映射新建绑定版本，不覆盖已确认业务用例。协议揭示业务冲突时提出新用例候选版本待核对，保留旧版本和历史证据。旧 Excel/JSON 是导出快照，不随绑定自动变更；重新导出生成新文件。外部修改过的用例回导须核对身份和内容，不能只凭编号覆盖。

绑定页“确认本条映射”表示人工核对后保存这一条用例的技术映射；提交时校验适用的必需项，缺项不能确认完整。“按需补充”是适用项提示，不表示可跳过必需字段或必要清理。该动作不直接授予可运行状态，部分映射可保存草稿。

“待协议绑定 → 映射待核对/有缺项/业务冲突 → 绑定已确认 → 可生成脚本 → 脚本待核对 → 可运行”分别记录。完整绑定后仍须满足对应执行器、非生产环境与角色、测试数据、业务观察及适用的清理条件；协议更新或用例变更需重新检查既有脚本适用性。收到 ACK 或状态码不能替代原业务预期。

共享操作为：生成脚本、基于问题修订、从头重新生成、需求核对、单条/选中/项目范围的已有脚本复跑、版本与执行证据。前面三项调用模型；复跑已有脚本为零模型。生成与运行分别有确认内容，运行会创建新批次，旧用例、脚本和结果保留。未批准的技术试跑与正式批准状态分开，条件不足按条目记录原因；部分执行不能包装成整个项目通过。

UI 的页面定位、浏览器会话、截图/录像，对应后端的协议/命令绑定、通信会话、脱敏请求/响应、业务状态及清理证据。通讯协议只描述格式时，仍需补足业务判定依据。协议类型尚未确定，草图没有承诺 HTTP 或所有协议已经支持。

执行页面以列表为主体，支持分页、搜索、状态筛选和批次切换。当前示例统计范围明确为“当前类型与批次”：全部 24 = 通过 16 + 失败 3 + 阻塞 2 + 未执行 3；筛选后显示 5 条失败/阻塞，用例列表条数与全批次统计不混用。列表直接展示失败摘要及预期/实际，完整步骤与媒体在详情中查看；相同报错可展开分组，分组归因只作排查建议。

批量处理先显示实际选中范围，组选择和跨页选择不得混淆。原脚本复跑不调用模型，每项重新检查版本与执行条件；新批次保留旧结果。反馈修订保留原业务预期并核对新脚本；被测产品缺陷不能靠修改断言消除，环境/认证阻塞先恢复执行条件。选中集合中的不适用项明确显示原因，不静默跳过或覆盖失败。

用户已同意共享流程与当前草图方向，实施不再重复申请该方案的确认。来源查看方式可比较并排或下方布局；具体界面仍需产品实现后的真实浏览器验收。
