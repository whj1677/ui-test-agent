# 版本33：成功补证后再次核验收尾

## 真实起因

v32 round-yEXcww 先由内部完成候选检出缺页码，Agent已实际补测原第1页且审查ACCEPT，但每步completionProposed只能一次。标志耗尽后只能继续开放规划，模型重复标题导致ADAPTIVE_NO_PROGRESS。实际4断言无业务差异不等于完整步骤；后续未执行，旧失败不改。

## 有限修改

内部收尾候选从“每步至多一次”改为“每组不同成功测量声明至多一次”。completionEvidenceKey只接收控制器在本原步骤保存的成功执行片段，提取目标/谓词/预期，规范可见性默认true，去重排序后散列。重复同一断言、重贴来源ID/引文、动作或段编号、顺序、说明文字、超时都不构成新证据。该指纹不是DOM别名或任意逻辑等价判定，不能单独证明语义完整。

提请条件仍为：有真实成功测量、原全部义务MEASURED_COVERED、最近执行审查ACCEPT且无issue、无待修正状态。候选仅空动作/空断言complete:true，继续经过完整来源、目标、原动作/时序、必要证据和独立最终审查。被拒不能改通过。

空收尾候选内容可能完全相同，因此旧拒绝去重只对控制器自产候选加入成功证据指纹；普通模型候选不改变去重规则，模型不能提供origin/hash字段绕过。保留每次拒绝和实际指纹。只重新核验完成，不重放业务动作或重测已成功断言。

原每步8段、20断言、2次语义纠错、步骤期限、模型调用上限保持，拒绝仍按原额度计数。新测量实际失败/未知派发/权限问题仍立即停止，不进入重新收尾。重复或元数据变化不触发无限核验。
