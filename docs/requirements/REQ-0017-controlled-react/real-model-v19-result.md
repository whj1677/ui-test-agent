这是必要来源检查，不是自然语言等价证明。阿拉伯数字与部分明确中文数词可识别，模糊或未支持表达是能力缺口；全局总数、当前页数量、其他对象数量仍需独立核验范围。V07默认排序/条件清空的原义务覆盖问题不属于本批已修范围，后续继续处理。
