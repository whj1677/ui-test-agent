# 版本35：原文位置区间与绝对行号

## 问题与有限修复

版本33原V01的“第1至5行依次为…”原位置要求因来源解析不支持而被降成相对顺序。对原实际矩阵前插一行的只读反例仍满足旧断言，属于漏验，不是正常完整；旧轮次、原题及失败记录不改。

本版共享来源解析把明确第N至M行的逐项原身份映射到绝对行号，复用既有table_cells.position实际比较、能力事实与完成守卫。只支持当前肯定范围、阿拉伯1..999或中文一..十、至/到/连字符/波浪线、最多50项顿号分隔且每项开头明确ASCII字母数字身份；不根据编号后缀、DOM或模型补齐。识别到肯定范围但不支持或有歧义时，完成态保留来源缺口，不允许降成相对顺序。负面、条件、历史、示例不据此生成正向要求。

位置范围终点不再成为精确行数来源；第2至4行不意味着全表只有4行，也不授权exact_rows。原文另外明确的总数量继续独立校验。预算、原动作不得重放、真实差异不得修成通过、权限和预期保持。没有用例ID或URL专用分支，没有放宽自由代码或动作类别。
