## 实现与边界

生产Controller对当前原步骤先独立解释，再以无页面/无候选的输入独立复核；逐原义务保留INTERPRETED或UNINTERPRETED、测量类型/原预期/前后检查时机。私有执行上下文冻结并绑定原文哈希，候选不能写入或降级；解释耗时与请求计原预算。

已复核位置关系作为旧词法之外的来源依据，原键/值、对象、定位与实际DOM比较保持。成员/按键值/相对顺序不能替代原位置，操作前证据不替代操作后。未知义务不能完成；目标待绑定、证据不足、实际差异分开保存在事实与事件。原Case不写回，候选契约不是测量证据。未来表不存在时仍可执行原授权点击。

这是独立源解释加类型/时机的必要校验，不是任意自然语言等价证明；语义解释及复核仍依赖模型。旧英文句末紧邻编号的句点会导致编号来源拒绝，作为明确限制保留，不为此放宽编号匹配。低层BrowserSession旧测试适配器可不提供源解释，但不能用该路径冒充生产Controller验证。
