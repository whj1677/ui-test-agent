# 版本10：首批通用缺口与持续测试基础

## 边界

用户要求修复版本9并减少手工输入Key/点击登录。修改前已更新REQ-0017版本10及REQ-0016版本2事实源。原32条输入、预期、故障页面及版本9失败记录不变。本批不是全部缺陷修复或发布验收。

## 实际改动

- 登录完成后父任务离开WAITING_USER_LOGIN；当前prepare/run按对应流程展示，避免直接测试界面隐藏登录确认入口。
- 准备阶段单例模型JSON/协议错误保留映射失败并继续未开始用例；认证、网络、持久化及停止错误不被吞掉。不重放已执行动作，不把跳过计成功。
- 采集相邻dt/dd的字段名和值，对已有合法data-field属性生成受范围/唯一性/原节点核验的技术绑定。同弹窗重复属性拒绝，错误字段不能从历史文字或其他对象借正确值。无稳定属性等剩余布局不虚构定位。
- Windows模型Key持久化为显式可选项：默认内存，勾选后当前账户DPAPI加密，重启恢复、可忘记、损坏不覆盖，无明文回退。配置变更与作业启动互斥。真实业务登录凭据仍不保存。
- 新的维护入口`node scripts/autonomous-lab.mjs`默认无模型预检；`--real-model`使用已有加密配置，创建独立浏览器与自己拥有的合成站点，自动进入并核验首页。共享调用数/时间上限，逐请求记账；全32条中6写入仅准备，不越过计划批准。此脚本不自行改产品源码，后续代码修复仍由维护Agent完成。

DPAPI技术边界参考[Microsoft ProtectedData](https://learn.microsoft.com/zh-cn/dotnet/api/system.security.cryptography.protecteddata?view=windowsdesktop-9.0)：当前账户范围不是抵御该账户恶意进程/管理员的保证。旧运行版没有安全导出接口，初次迁移需本机保存一次，不读取旧进程或聊天中的Key。
