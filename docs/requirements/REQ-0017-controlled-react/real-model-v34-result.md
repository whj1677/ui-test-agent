## 有限实现

严格原义务审查之后，仅对部分候选中当前断言未被全部同来源COVERED支持或被负面检查引用的条目追加一次细粒度核验。目录和当前片段尾部身份由控制器核对；旧已执行断言不再次核验，模型不能挑选待验引用。补充回复只允许每必需引用一条SUPPORTED/CONTRADICTS/UNRESOLVED及理由，缺项/重复/未知引用或字段/空理由/坏JSON拒绝整个未执行片段，原额度内交回规划；不静默删断言或只执行其中动作。

SUPPORTED仅许可合法局部断言实际执行，原MISSING/REPAIR保持，不能宣布义务完成。CONTRADICTS、UNRESOLVED与格式错误不会生成业务失败；原非GAP拒绝仍直接拒绝。纯动作和已获明确支持的当前断言不加调用；附加调用使用原Controller审查通道、deadline/取消/调用账本。网络/预算失败传播，不无限重试。完整候选和最终审查未放宽。

Kimi只读会诊支持双粒度方向；见kimi-v34-review.md。未采纳其“只阻断CONTRADICTS”或默许缺字段的建议。仍存在同模型误差相关性，不把多一次调用当正确性证明。
