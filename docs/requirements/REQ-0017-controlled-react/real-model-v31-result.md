# 版本31：查询条件要有同一步结果证据

## 真实起因与范围

v30 round-A1zImh 的 V02 虽有4步16断言通过标签，S03仍只验了关键词输入框，未验结果名称；S04名称不能补S03的AND时机。这是覆盖缺口，不计完整通过，不修改旧运行记录。

本版仅加必要证据守卫，不把正则或候选标签当语义批准：明确肯定的“条件按/以AND生效”，从当前查询前或紧邻前一步原输入中提取引号字段的字面关键词/选择条件。没有页面反推、未来步骤借用、自动补输入或改原期望。排序不当作结果字段；重置/跳页/条件/否定/未知输入格式、非关键词自由输入匹配语义、“全部”等不能推断的值保留具体能力缺口。最多8个条件，拒绝歧义或省略输入子句。

当前步骤完整候选中，每个参与证明的同表同记录key，必须以cell/table_cells字段测量分别支持原条件；控件value/selected_label、行数、ID不能单独代替，跨行跨表不能拼接，两个独立同值条件不能复用一列。原关键词允许对应结果字段contains，不猜业务字段别名。原明确结果为空可用同义务的实际row_count=0或空exact_rows矩阵，不能为验证AND发明一条记录。

这是必要条件，不证明任意表结构、所有筛选算法、全集完整性或字段对应的自然语言语义；独立审查、原数量/来源/时序核验和现场执行继续负责这些。未知语法不承诺自动支持。固定计划不变，部分片段可以先查询后补证，原恢复预算不增加，已经执行的查询不重放，真实字段差异不重新规划成通过。
