规划和审查共享明确原键负向能力及范围说明：键来自原用例，table/列来自观察，排除键不必先出现；仅证明当前完整渲染表，不推所有分页、整页或未来状态。审查目录增加程序派生planned_sampling_group，区分拟同检查点组合与不同时间；仅元数据，不能宣称已测。局部合法有用与整体充分分离，不强求每个组件独立证明整个复合义务；仍不覆盖UNRESOLVED、负面审查、原MISSING或原预算。Kimi只读会诊及未采纳项见kimi-v36-review.md。
