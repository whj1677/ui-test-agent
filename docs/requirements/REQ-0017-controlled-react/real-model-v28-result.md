## 有限修复

selection-timing识别当前原步骤肯定字面切换到/切换至/切回/点击/选择X页签或标签页。若候选要测同名精确role tab的aria_selected=true，当前原步骤在此前或同一checkpoint必须已有同目标click。后续checkpoint、其他对象或前一原步骤不能倒填动作依据。

该必要时序在complete:false和true均检查；提前候选返回ASSERTION_SELECTION_BEFORE_ACTION，由原额度修正，运行器不补动作、不重放。语义等价但定位表达不同的已执行目标需要复用绑定，不能再点击。原默认/初始/明确操作前状态不由此重解释；否定/条件/示例/其他未支持表达仍独立审查。真实点击后未选中继续业务失败，不能根据当前值改预期或重试成成功。

这不是所有操作的通用时序推理，也不证明完整覆盖；源依据、对象、字段、原业务判定和时间窗口继续保持。
