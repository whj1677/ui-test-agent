# 可复用经验索引

## 结论

本目录用于沉淀 `ui-test-agent` 中具备跨任务复用价值的技巧、模块、方案、脚本、配置方法、测试方法和排障经验。

## 写入规则

1. 可复用内容必须说明适用场景、使用方式、依赖条件、注意事项和关联路径。
2. 一次性问题放 `docs/ai_engineering/06_known_issues.md`。
3. 可重复使用的方法放本目录。
4. 不记录密钥、账号、内网敏感地址或生产数据。
