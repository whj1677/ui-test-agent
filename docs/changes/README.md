# 变更记录

无语义变化的注释、展示文案、排版和普通局部修复无需单独记录。仅当用户或项目明确要求留档、或问题确需后续追踪时，才在 docs/changes/daily.md 追加日期、问题、修改与实际验证；只追加与当前任务直接相关的已有需求，不因项目中存在其他需求而关联。日常记录不放在此受管块内，以免后续模板升级覆盖。

## 正式 FIX 兼容

仅显式选择正式 Quick Fix 交付时使用 _quick_fix_template.md 的 fix-record-v1；原资格、真实单元/集成测试和证据约束保持不变。既有正式记录不自动降级为日常摘要。业务/验收或高风险影响使用真实 REQ。
