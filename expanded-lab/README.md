# 扩展 UI 对照测试

本包补充原 `manual-lab`，不覆盖其页面、用例或历史任务。32条完整分母：原12只读、6草稿/写入、4待澄清、2已知缺陷，加本包8条配对用例。业务依据见[SPEC](SPEC.md)，机器判分依据见[oracle.json](oracle.json)，后者不得导入Agent。

## 使用

在项目目录运行 `node expanded-lab/serve.mjs`，访问 http://127.0.0.1:4197/ 。无需真实账号或密钥，页面没有外部网络。新建Agent任务、目标填写该首页、导入[cases.json](cases.json)，仅授权本机只读。首页“运营总览”可作为当前页面确认标志。

八个视图中有四个故意错误。不要修复被测页面、修改用例预期或将模型技术阻塞算作检出错误。新站点不是Agent控制台的新版本。

## 分层验证

- `node --test --test-concurrency=1 expanded-lab/verify.test.mjs manual-lab/verify.test.mjs`：参考浏览器验证实际页面和独立真值，不是Agent自主测试。
- `node expanded-lab/check-freeze.mjs`：核验原页面/输入及新配对资产摘要，不证明业务测试结果。
- 真实模型：通过产品入口导入、确认、运行；只给用例和页面，不给定位器、技术计划或判分答案。每条保存原步骤、实际测量、终态及证据，汇总不得忽略未执行项。

合格负例必须在正确对象及字段上实际测到规格差异。`TECHNICAL_FAILED`、`BLOCKED_MAPPING`或断言其他内容不符合均不能冒充目标缺陷检出。写入例须走既有写入审批/清理路径，不能利用只读通道绕开；未运行标记缺口。
