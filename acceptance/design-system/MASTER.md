# 合成验收站设计基线

REQ-0004；用于夹具，不改 Agent 控制台。ui-ux-pro-max 检索校验后采用数据密集型后台/简洁布局；拒绝首次误匹配的营销 Hero/CTA 结构，不接入推荐中的外部字体或组件包。

- 系统字体：Segoe UI / Microsoft YaHei / sans-serif，无外网字体。
- 蓝色主操作 #2563EB，正文 #1E293B、次级文字 #475569、背景 #F8FAFC、白色卡片、边界 #CBD5E1。正文与背景对比不低于4.5:1。
- 表单清晰标签、键盘可达、可见 focus ring、模态焦点隔离与关闭后归位；提示不只靠颜色。触控目标至少44px。
- 1440px、375px窄屏及短屏检查；模态自身可滚动，不用页面横向溢出解决布局。尊重 prefers-reduced-motion。
- devices：原表格页面字节保留，不以设计规范覆盖历史样本。
- work-orders：顶部导航、卡片分页、自定义抽屉与 portal 说明，刻意保留同名卡片与重复按钮。
- requests：侧边导航、三步向导、联动字段、原生叠层 dialog、受控内存 CRUD。

不能为定位成功新增隐藏答案、专属测试按钮名、唯一测试选择器，不能修掉冻结的预置产品错误。参考检查可用定位技术核验夹具，但这些代码不供 Agent 使用。
