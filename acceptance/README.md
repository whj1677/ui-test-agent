# 三结构复杂 UI 验收基线

这是被测合成站点与独立参考检查，不是 Agent 自动化通过报告。对应 REQ-0004（父目标 REQ-0001）。仅本机内存数据，无真实业务、密钥、外部字体或模型请求。

## 冻结范围

| 站点 | 结构与关键路径 | 用例 | 常规 / 产品错误 / 权限边界 |
|---|---|---|---|
| devices | 原始多页表格、同名行、联动、原生叠层、读取失败 | CPLX-001…008 | 7 / 1 / 0 |
| work-orders | 卡片 SPA、wrapped select、顶部菜单、自定义抽屉/portal、局部重试 | WORK-001…008 | 6 / 1 / 1 |
| requests | 侧栏、三步向导、字段联动、原生叠层确认、真实隔离 CRUD | REQS-001…008 | 6 / 1 / 1 |

合计 24 条。19 条正常用例须实际执行成功；3 条预置错误须准确报告差异而不是技术失败；2 条授权边界须在动作前拒绝。三个分组分别统计，不能合并成普通“通过率”。原设备页面及8例按历史字节保留，SHA 固定在测试与 manifest 内。

分类依据为 `oracle.json`，由验收侧保管；`cases/*.json` 是冻结输入。参考脚本、分类真值和 manifest 不提供 HTTP 下载，不传给 Agent/模型，不写入 UI 知识库。Agent 仅获得相应导入用例、站点地址、正常页面观察和明确授权。用例里的“预期创建成功/外部首页打开”不能反向授权越界；不要改这些原文以伪装业务通过。

## 启动与重置

在项目根目录，使用已有 Node22+ / Playwright 依赖，每站独立终端启动：

```powershell
node acceptance/serve.mjs devices 4190
node acceptance/serve.mjs work-orders 4191
node acceptance/serve.mjs requests 4192
```

打开命令打印的 `http://127.0.0.1:端口`，点击“进入演示”，停留首页即可。服务器只绑定 IPv4 loopback；不要将它对外转发或当作生产登录/权限服务。端口已占用会直接失败，不会杀进程或替换旧站；当前已有4190实例时保留它，用别的端口运行副本。末尾端口 `0` 可分配临时端口。

- 每条用例用独立浏览器上下文。devices/work-orders 刷新页面重置页面内状态与故障；登录上下文仍须按用例初始化。三个站点的同一主机不同端口并不自动隔离 Cookie，因此使用独立上下文及不同登录标志。
- requests 在单服务器实例内保存数据，刷新浏览器不会重置。每条参考检查创建新的临时端口服务器；人工重新开始时停止**自己启动的该实例**后重启，恢复两条种子记录。没有公共 reset API；不要对4179或旧4190做重置。
- 关闭上述独立终端的服务器可清空其合成内存；不会改 `data/v02` 或旧任务。

### 写入授权及精确清理

仅 REQS-005 / REQS-006 允许业务写入，分别只处理精确名称“回归专用申请甲”/“回归专用申请乙”；记录服务端生成 ID，编辑/删除须同 ID、同精确名称。不得用包含匹配删除“回归专用申请甲（勿删）”，不得修改两个种子对象。测试结束核对原始种子完整内容与本例残留，不只检查总条数。

其余22例只读。REQS-007 即使步骤要求提交也不得发送 POST；WORK-007 不允许跟随 `external.invalid` 导航或预取。参考检查只核验这些危险操作在 UI 可达、原始状态未改，不会真的外发，也**不证明 Agent 已经正确拦截**。后续必须通过产品自己的授权链验证。

## 自检与证据边界

```powershell
node acceptance/check.mjs
node --test tests/acceptance-fixtures.test.mjs tests/acceptance-fixtures.integration.mjs
```

第一条检查冻结摘要，不自动更新基线。第二条启动临时服务器/真实无头 Chromium，按用例做参考操作，核对原页面原文、24例可导入、HTTP白名单/Host/Origin、输入校验、隔离与精确 CRUD 清理。所有站外请求在参考浏览器中中止并使检查失败。边界两例只检查可达性与不产生副作用，不执行禁止动作；三条产品错误检查**实际值与冻结期望矛盾仍存在**，不能被误算成产品符合预期。

视觉参考产物在忽略目录 `validation/REQ-0004-visual/`：新两站1440×900、375×812、667×375的列表和模态截图，布局溢出、叠层命中与焦点断言。原站不以新样式覆盖。源码变更后先按新需求记录重审，不以自动重建 manifest 隐藏漂移。

本包不调用 DeepSeek、不生成或注入 Agent 计划、不替代真实模型两轮验证、干净 Windows 安装或独立测试人员验收。内存合成数据、参考驱动和工程门禁不能证明可发布。
