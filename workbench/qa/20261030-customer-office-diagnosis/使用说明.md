# 测试Agent现场诊断包 v1

适用于本次 wps3 x64 安装包，采集 WPS 读取失败、DSH 锁和 Node 启动错误的技术线索。这是诊断工具，尚未修复用户电脑上的问题。

1. 完整解压到可写文件夹，不要在压缩包内直接运行。
2. 按平时方式打开测试工作台，双击 **双击诊断.cmd**。
3. 如提示选择安装目录，选择包含 `program` 的目录，或 `program` 目录本身。
4. 选择刚才读取失败的 `.docx`。取消则只采集环境、宿主锁和 Windows 应用错误事件。
5. 等待提示“报告已生成”（通常约 1 至 3 分钟），将同目录的 **现场诊断-时间.json** 发回。即使其中检查失败，也请保留报告。

无需安装 Node，无需重装工作台。本工具使用工作台自带的 Node；若 Node 启动失败，则保留 PowerShell 采集的报告。如果出现 Node 应用错误弹窗，关闭该弹窗后等待诊断窗口完成。

采集范围与边界：

- 不调用模型、不自动发送报告，不覆盖已安装程序，不启动第二个工作台。
- 不删除 DSH 锁、不终止 DSH 或工作台进程，不更改系统配置或权限。
- 不读取凭据配置；报告不保存文档正文、密码或模型密钥。
- 文档仅复制到临时目录，由安装版和诊断版 Office 读取器分别测试临时副本。原文档路径不交给 Office 打开；检查前后原文件摘要并记录临时文件清理结果。
- 可能短暂启动独立的 Word/WPS 实例，仅按现有读取器的归属机制清理本次实例。
- Windows 应用事件仅保留时间、事件类型、应用/模块文件名、异常码等字段，不导出完整消息、命令行或转储文件。
- 命令路径检查在 DSH 沙箱外执行，不能用它代替沙箱内的执行结果。
- JSON 含版本、进程 ID、文件摘要等技术元数据，请仅发给项目维护人员。

企业保护策略可能让个别检查失败。不要因此修改注册表、关闭安全软件或反复运行测试，保留原始报告即可。
