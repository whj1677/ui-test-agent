# 设备库存台（合成试点夹具）规格说明

## 0. 性质与真值声明
- 本站为完全合成的本地测试夹具：无真实凭证、无真实业务数据、无外部网络访问、无真实持久化（会话仅存内存，进程退出即消失）。
- 本文件是唯一业务真值来源。`server.mjs`、`index.html`、`cases.json` 均必须由本规格派生；禁止以 `cases.json` 反推或修改业务真值，禁止为让测试通过而改动本规格所列数据。
- 站点性质：本服务是“被测目标站”，不是测试工作台。

## 1. 运行与绑定
- 运行方式：`node server.mjs`；Node.js 原生 `http` 等内置模块，零第三方依赖、零构建步骤。
- 默认绑定 `127.0.0.1:4381`；支持 `--port <端口>` 修改；本夹具不使用端口 4322。
- 仅服务本规格第 3 节列明的路由与随附的 `index.html`；不存在任何文件路径拼接式静态服务，无目录遍历风险。
- 全部业务写操作不存在：仅查询与浏览器本地选择，无保存、提交、审批或任何真实修改。

## 2. 固定账号与会话
- 固定合成账号：`account_id = "synthetic-inspector"`，`role = "inspector"`。无用户名/密码输入框，登录仅由登录页上标注“公开合成账号登录”的按钮触发。
- 会话为内存 Map；Cookie 名为 `sid`，属性固定为：`HttpOnly; SameSite=Strict; Path=/; Max-Age=1800`。
- 会话有效期 30 分钟；`expires_at` 为有效 ISO 8601 时间字符串。
- `POST /api/logout`：销毁当前会话并以 `Max-Age=0` 清除 Cookie。
- `POST /api/expire`：仅供本合成站“模拟会话到期”使用，行为与 logout 相同（销毁会话、清 Cookie）；工作台页面有可见按钮“模拟会话到期”，点击后页面出现“会话已到期”的可见提示并自动返回 `/login`。

## 3. 路由与响应契约
| 路由 | 方法 | 未登录 | 已登录 |
|---|---|---|---|
| `/` | GET | 302 → `/login` | 302 → `/login` |
| `/login` | GET | 200 HTML | 200 HTML（页面提示已登录并给出进入工作台链接） |
| `/workspace` | GET | 302 → `/login` | 200 HTML |
| `/api/login` | POST | 200 JSON 身份 + 种下会话 Cookie | 同左（重复登录会重建会话） |
| `/api/identity` | GET | 401 JSON | 200 JSON，精确包含：`authenticated:true`、`account_id:"synthetic-inspector"`、`role:"inspector"`、`expires_at:<有效ISO字符串>` |
| `/api/logout` | POST | 200 JSON（幂等，清 Cookie） | 200 JSON，销毁会话、清 Cookie |
| `/api/expire` | POST | 200 JSON（幂等，清 Cookie） | 200 JSON，销毁会话、清 Cookie |
| `/api/devices` | GET | 401 JSON | 200 JSON 列表，固定延迟约 500ms |
| `/api/devices/{id}` | GET | 401 JSON | 200 JSON 详情，固定延迟约 500ms；id 不存在返回 404 JSON |

- 统一错误 JSON 形态：`{"error": "<代码>", "message": "<中文说明>"}`。未登录/会话失效：`401 {"error":"unauthenticated","message":"未登录或会话已失效"}`；设备不存在：`404 {"error":"device_not_found","message":"设备不存在"}`；未知路径：`404 {"error":"not_found","message":"资源不存在"}`；已知 API 路径的错误方法：`405 {"error":"method_not_allowed","message":"方法不允许"}`。

## 4. 固定业务数据（真值表，禁止改动）
| 编号 | 名称 | 型号 | 库位 | 库存状态 | 可选状态 |
|---|---|---|---|---|---|
| INV-101 | 温控采集器A | TCA-100 | A-01-01 | 在库（充足） | 可选 |
| INV-102 | 温控采集器B | TCA-100B | A-01-02 | 在库（紧张） | 可选 |
| INV-103 | 电池巡检仪 | BPI-200 | B-02-01 | 在库（充足） | 受限不可选 |
| INV-104 | 温控采集器C | TCA-100C | A-01-03 | 在库（充足） | 可选 |
| INV-105 | 电源模块 | PSU-500 | C-03-01 | 在库（紧张） | 可选 |

- 受限原因固定文案：「该设备为受限资产，当前角色 inspector 无权选择」。
- 详情页“权限提示”：可选设备显示「当前角色 inspector 可选择该设备」；INV-103 显示上述受限原因文案。

## 5. 列表、筛选与分页真值
- 排序固定按编号升序；每页固定 2 条。
- 无筛选：共 5 条、共 3 页。第 1 页 = INV-101、INV-102；第 2 页 = INV-103、INV-104；第 3 页 = INV-105。
- 筛选语义：名称包含所输入子串（子串匹配，区分是否为空；空串视为无筛选）。
- 筛选「温控」：命中 INV-101、INV-102、INV-104，共 3 条、共 2 页。第 1 页 = INV-101、INV-102；第 2 页 = INV-104。
- 列表行展示字段：选择复选框、编号、名称、库存状态、可选状态（文案为「可选」或「受限不可选」）、操作（“查看详情”按钮）。INV-103 行的复选框必须为 `disabled`，且行内可见受限原因文案。
- 分页指示文案：「第 X 页 / 共 Y 页（共 Z 条）」，并有“上一页”“下一页”按钮，越界时相应按钮禁用。

## 6. 异步与加载提示
- 列表查询与详情加载各有固定约 500ms 服务端延迟（稳定落在 400–600ms 区间）。
- 列表加载期间可见提示文案「正在加载设备列表…」；详情加载期间抽屉内可见「正在加载设备详情…」；加载完成后提示消失。

## 7. 详情抽屉
- 点击行内“查看详情”按钮，以抽屉（`role="dialog"`）展示：编号、名称、型号、库位、库存状态、权限提示。
- 抽屉内“关闭详情”按钮关闭抽屉并返回列表；列表的筛选条件、当前页与勾选状态保持不变。

## 8. 选择规则
- 勾选状态仅存于浏览器内存，跨页翻页保留；刷新页面或会话失效后清空。无保存、提交、审批或任何真实修改入口。
- 已选区域固定可见，文案：「已选 N 台：编号1、编号2」（0 台时显示「已选 0 台」），编号按勾选集合排列。
- 取消勾选即从已选集合移除；INV-103 永远无法进入已选集合。

## 9. 会话到期可见提示
- 点击“模拟会话到期”后：页面出现「会话已到期」可见提示，随后自动跳转 `/login`；此后 `GET /api/identity` 返回 401，直接访问 `/workspace` 再次被 302 重定向到 `/login`。
- 任何业务 API 在使用过程中返回 401 时，页面同样给出到期提示并返回 `/login`。

## 10. 案例断言锚点（供 cases.json 对照，cases.json 不得反向定义真值）
- A1：未登录 GET `/workspace` → 302 到 `/login`，登录页可见“公开合成账号登录”按钮。
- A2：登录后 `GET /api/identity` → 200，精确字段见第 3 节。
- A3：点击“模拟会话到期”→ 可见到期提示、返回 `/login`；`/api/identity` 变 401；`/workspace` 重新受保护。
- A4：筛选「温控」→ 加载提示可见，结果共 3 条 2 页，顺序 INV-101、INV-102、（第 2 页）INV-104。
- A5：筛选「温控」第 2 页的 INV-104 详情抽屉字段 = 第 4 节真值表对应行 + 权限提示「当前角色 inspector 可选择该设备」；关闭后筛选条件与当前页保持不变。
- A6：无筛选跨页勾选 INV-101（第 1 页）与 INV-104（第 2 页）→ 已选区域显示「已选 2 台：INV-101、INV-104」；INV-103 复选框禁用且原因可见；翻至第 3 页后已选计数与列表保持不变。
