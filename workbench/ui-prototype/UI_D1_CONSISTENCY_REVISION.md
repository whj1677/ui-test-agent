## 修订结论

1. 用例版本现在保存完整正文：前置条件、测试数据、步骤及逐步预期都属于具体版本。历史详情按所选版本读取，不再从用例顶层读取最新版正文。
2. 创建建例任务时会把完整输入复制到 `inputSnapshot`。任务详情只读取冻结快照；快照缺失时明确显示不可追溯，不使用当前用例内容补齐。
3. 建例任务阶段条改为确定性映射，分别显示待开始、进行中、已完成、错误和未知。技术验证只有在正常试跑、反例、步骤映射和业务核对均满足时才完成；范围待确认不会被正常试跑通过掩盖。
4. JSON导出改为向原型静态服务的受控 `/demo-download` 端点提交演示包，服务只回传通过schema和`demo_only`检查的JSON附件，不持久化内容。

本批只修原型数据与交互，不迁移生产存储，也不改变生产状态机。

真实Chromium读取四类任务：

- 新建未启动任务：生成、技术验证、人工核对和登记均为“待开始”。
- 生成中任务：候选生成为“进行中”，技术验证仍为“待开始”。
