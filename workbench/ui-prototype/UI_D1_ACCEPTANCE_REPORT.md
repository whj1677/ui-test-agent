## 当前能力边界

可直接复用现有后端能力的区域：项目/用例/版本、Excel与JSON包预览确认、单条任务读取、登记运行与媒体读取。单条建例、候选验证和已首审资产运行仍是限定场景能力。

尚未实现且原型没有伪装可用：批量执行、通用Web审批、通用环境管理、多人权限。原型不构成正式UI替换，也不构成产品发布验收。
