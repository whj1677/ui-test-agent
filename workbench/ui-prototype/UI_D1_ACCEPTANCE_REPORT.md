## 尺寸、媒体与可访问性

- 1280×800、1440×900、1920×1080：六页逐一读取 `scrollWidth` 与 `clientWidth`，18/18均无页面级横向溢出，主标题均在初始视口可见。
- 录像使用原生 `video controls`。实测播放、暂停和拖动进度；步骤切换仅替换 `#step-detail`，不会重建播放器。
- 焦点样式、语义按钮/表单、弹窗焦点陷阱、Esc关闭与焦点返回已实现。
- 页面没有外部字体、分析服务、远程媒体或第三方网络依赖。
- 合成截图和录像不是业务执行证据；录像没有步骤时间戳，Trace没有伪造下载。
