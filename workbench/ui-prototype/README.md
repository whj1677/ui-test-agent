# UI-D1 测试工作台交互原型

这是与正式 `workbench/web` 分离的纯前端交互原型。所有项目、用例、任务、运行结果和媒体均为合成演示数据；页面操作不会调用工作台 API，也不会启动 Harness、模型或业务脚本。

## 启动

在仓库根目录执行：

```powershell
node workbench/ui-prototype/serve.mjs 4321
```

然后打开 <http://127.0.0.1:4321/>。服务仅监听 `127.0.0.1`，不需要安装新依赖。

## 可操作流程

1. 项目列表 → 创建项目 → 选择 Excel / 平台用例包 → 字段映射 → 导入预览 → 返回用例列表。
2. 用例库 → 打开用例 → 查看内容版本、建例任务、待处理问题和关联运行。
3. 执行记录 → 打开正常或反例记录 → 查看中文步骤、预期/实际、截图、录像和 Trace 说明。

刷新页面会恢复初始演示数据。批量执行、通用 Web 审批和环境管理仅显示真实能力边界，不提供伪可用入口。

## 文件边界

- `index.html`、`styles.css`、`app.js`：原型本体。
- `assets/`：公开合成截图与短录像，不含真实运行媒体。
- `evidence/`：浏览器验收截图。
- `DESIGN_NOTES.md`：页面结构、状态和 API 接入矩阵。
