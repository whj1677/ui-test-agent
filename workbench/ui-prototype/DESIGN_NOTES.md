# UI-D1 页面结构与交互说明

## 设计方向

依据附件 `测试工作台_UI原型需求说明_砂岩陶土_v1.0.md`，原型采用低饱和砂岩底色、陶土棕主操作、浅色侧栏和高密度表格。配色预览只用于核对视觉方向，页面结构、状态语义和操作规则均以需求说明为准。

核心色值：应用底色 `#F5F3EF`、侧栏 `#ECE7E0`、内容面 `#FFFDF9`、边框 `#DCD4CA`、正文 `#332F2B`、次级文字 `#6C635B`、主操作 `#805E49`、主操作悬停 `#6B4C39`、浅陶土 `#EEE1D5`。没有蓝色主导航、渐变、玻璃效果或用大卡片代替业务表格。

## 页面与任务关系

| 页面 | 默认突出 | 技术信息位置 |
| --- | --- | --- |
| 项目列表 | 名称、说明、用例数、最近活动 | 无 |
| 项目用例库 | 编号/标题、内容状态、自动化状态、最近结果 | 来源批次作为次级文字 |
| 导入向导 | 来源、映射、五类预览、处理决定 | Schema与行位置 |
| 用例详情 | 成对动作/预期、版本、任务和脚本关系 | 内容哈希与代码折叠 |
| 建例任务详情 | 五阶段、生成/验证/人工状态和当前处理人 | 输入、模型记录、哈希、原始错误折叠 |
| 执行结果详情 | 中文步骤、预期/实际、截图和录像 | 脚本哈希、原始记录折叠 |

项目内导航固定为“用例库、建例任务、执行记录、项目设置”。脚本版本属于用例详情，不要求测试工程师先理解资产系统术语。

## 交互约定

- 项目创建后仍可重复导入；导入是独立页面，不是只能使用一次的创建步骤。
- 用例库每页25条，选择按内部ID保存；筛选或翻页后显示隐藏选中数，导出“选中”和“全部”明确分开。
- Excel与JSON包使用同一用例模型。预览显示新增、重复、同源冲突、待澄清、不能导入；冲突只有明确选择“作为独立副本导入”后才新增。
- 动作和预期属于同一步。保存编辑形成新版本；旧任务快照和旧脚本版本绑定保持不变。
- 建例任务的创建、候选生成、技术验证、人工核对、脚本登记是五个阶段，不合并成“成功”。
- 结果页切换步骤只更新文字区，不重建 `video`，避免播放位置和暂停状态被轮询式刷新重置。
- 没有步骤级视频时间戳，因此不提供“点击步骤跳到录像时间点”。Trace没有合成文件时显示不可用，不生成伪造ZIP。

## 状态语义

| 层级 | 示例 | 不等同于 |
| --- | --- | --- |
| 用例内容 | 内容已确认、存在待澄清项 | 脚本批准或测试通过 |
| 自动化 | 未建例、生成中、待人工核对、已有适用脚本 | 候选已批准 |
| 原始执行 | 通过、断言不符、运行中断、证据缺失 | 产品缺陷归因 |
| 业务核对 | 检查范围待确认、可进入人工核对 | 真人批准 |
| 人工状态 | 未进行、范围待确认、待核对 | 脚本自动登记 |

页面持续显示“交互原型／演示数据”。所有状态、截图和录像只用于交互评审，不是正式执行证据。
