# 设备台账练习目标与范围 v1

仅用于本地合成练习，资料待操作者核对，无真实客户或账号。
体验目标：资料导入 → 前端/后端用例设计 → 人工逐条核对 → 当前版本用例入库 → 脚本或 HTTP 计划准备 → 人工审阅与显式执行 → 历史、媒体和报告查看。
本期只采用 01-PRD.md 的 R0/R1/R2/R3，不额外推断字段格式边界、角色体系或真实登录规则。

建议先分别生成：
- UI 范围：正常新增、重复编号拒绝、viewer 拒绝三个场景。使用页面输入、重新读回和精确清理。
- BACKEND 范围：同一三个场景。明确初始化、提交前独立读取、业务请求、提交后独立读取和清理，状态码与错误码见 03-PROTOCOL.md。

用例、脚本和报告是不同阶段的产物。内容确认不是脚本批准；模型提议需人工核对；未执行保留未执行状态。正常业务与预期拒绝分别按自身判据判断，不能将“所有提交成功”作为目标。
第一遍优先跑一条正常新增，再扩展其余场景。不要求一次覆盖未定义业务，不能为了结果变绿删去独立读回或改变原预期。
