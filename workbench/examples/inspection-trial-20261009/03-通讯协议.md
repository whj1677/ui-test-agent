# 巡检工单 HTTP/JSON 通讯协议 v1

仅用于公开合成练习。Base URL：http://127.0.0.1:4460。页面 /inspection/。无需登录，不使用真实密码、Token 或 Cookie。UTF-8 JSON；创建与初始化请求使用 Content-Type: application/json。公开角色 x-synthetic-role 是练习输入，不是认证。

## 数据与范围

runId 格式 [a-z0-9][a-z0-9-]{2,63}，每条执行独立新建；执行器引用 {{runId}}。初始列表：[{"code":"WO-1001","title":"PCS月度巡检","station":"EAST","priority":"HIGH","status":"PENDING"},{"code":"WO-1002","title":"消防设备检查","station":"WEST","priority":"NORMAL","status":"PENDING"},{"code":"WO-1003","title":"电池温差复核","station":"EAST","priority":"NORMAL","status":"DONE"}]。
code=WO-加4位数字，title 去首尾空白后1至60字，station=EAST/WEST，priority=HIGH/NORMAL，status=PENDING/DONE。列表按 code 升序。允许控制路径 /__control/namespaces 与业务路径 /api/v1/namespaces/。

## 初始化（仅 setup）

POST /__control/namespaces

JSON {"runId":"本次全新编号"}。已有编号不覆盖、不重置。

响应 201 {"runId":"当前编号","created":true}。已有空间响应 200 {"runId":"当前编号","created":false}。

## 列表查询

GET /api/v1/namespaces/{runId}/orders

可选 query code、station、status，精确匹配，多条件 AND；无过滤返回全部记录，total 是过滤后数量。

响应 200 {"runId":"当前编号","items":[{"code":"WO-1001","title":"PCS月度巡检","station":"EAST","priority":"HIGH","status":"PENDING"}],"total":1}。此示例对应 station=EAST&status=PENDING；无条件初始 total=3 且 items 为上述完整基线。

## 单条查询

GET /api/v1/namespaces/{runId}/orders/{code}

路径 code 是精确编号。

响应 200 {"runId":"当前编号","item":{"code":"WO-1001","title":"PCS月度巡检","station":"EAST","priority":"HIGH","status":"PENDING"}}；无记录响应 404 {"runId":"当前编号","error":{"code":"ORDER_NOT_FOUND","message":"工单不存在"}}。

## 新增工单

POST /api/v1/namespaces/{runId}/orders

请求头 x-synthetic-role=editor 或 viewer。JSON 四字段 code、title、station、priority。示例 JSON {"code":"WO-2001","title":"储能舱温控巡检","station":"WEST","priority":"HIGH"}。status 由服务赋 PENDING。

响应 201 {"runId":"当前编号","created":true,"item":{"code":"WO-2001","title":"储能舱温控巡检","station":"WEST","priority":"HIGH","status":"PENDING"}}。
响应 409 {"runId":"当前编号","error":{"code":"DUPLICATE_CODE","message":"工单编号已存在"}}：输入 WO-1001 等已存在编号，原记录不变。
响应 403 {"runId":"当前编号","error":{"code":"FORBIDDEN","message":"只读角色不能修改工单"}}：viewer 写入拒绝。
响应 400 {"runId":"当前编号","error":{"code":"VALIDATION_ERROR","message":"字段不符合要求"}}：字段无效。
所有拒绝的 items 与请求前逐字段相同，不得仅核对数量。拒绝 message 是非空中文，测试不要求文字逐字一致。

## 完成工单

POST /api/v1/namespaces/{runId}/orders/{code}/complete

请求头 x-synthetic-role=editor 或 viewer。不发送正文。editor 将 PENDING 转为 DONE；其他字段不变。

响应 200 {"runId":"当前编号","updated":true,"item":{"code":"WO-1001","title":"PCS月度巡检","station":"EAST","priority":"HIGH","status":"DONE"}}。
响应 409 {"runId":"当前编号","error":{"code":"ALREADY_COMPLETED","message":"工单已完成"}}：已有 DONE 不重复完成。
响应 403 {"runId":"当前编号","error":{"code":"FORBIDDEN","message":"只读角色不能修改工单"}}：viewer 拒绝。
响应 404 {"runId":"当前编号","error":{"code":"ORDER_NOT_FOUND","message":"工单不存在"}}。拒绝均不写入。

## 清理（仅 cleanup）

DELETE /__control/namespaces/{runId}

只删除本条用例自己的 runId。

响应 200 {"runId":"当前编号","deleted":true}；不存在时 deleted=false。生成的执行计划在任何结果下都要安排精确清理。

## 全局约束

未初始化或清理后的业务空间返回 HTTP 404，error.code=NAMESPACE_NOT_FOUND。初始化与清理必须处于执行计划 setup/cleanup，不放入业务 steps。每条用例只操作自身空间，不固定复用示例 runId，不清理其他用例。

健康检查 /health 和只读基线 /__control/baseline 用于环境维护，不属于本批后端业务 steps，不能充当业务断言。
