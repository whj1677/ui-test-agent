# 用例详情与复跑 UI 方案

2026-09-25 · 待用户核对的设计方案，不是产品实现或验收报告。

当前阶段：暂停产品实施，只形成页面和交互方案。输入为用户最新截图、独立详情页要求，以及仓库现有两份产品流程需求。有限交付为一个离线交互稿和本说明。停止点为交付方案；不接后端、不运行候选、不调用模型、不提交产品改动。

打开同目录 `index.html`。推荐先点击列表中的 **示例-03**，再切换媒体、页签、状态；返回列表体验选中或全项目复跑的确认流程。只有示例-03绘制了完整详情，其他行示范状态，没有复制真实项目资料。所有数字、用例和媒体均为设计示例，不是24条任务的新成绩。

## 页面方案

| 页面 | 用户在这里完成什么 | 主入口与交互 |
|---|---|---|
| 项目用例库 | 导入、搜索、选择、查看准备情况 | Excel导入；点击编号或标题进入独立详情；运行选中、运行全项目 |
| 独立用例详情 | 查看一个用例的正文、当前结果、证据和脚本 | 同一窗口独立路由，浏览器可返回；不在列表下方继续展开长表单 |
| 复跑确认 | 确认环境、软件版本、用例范围及可运行项 | 单条/选中/全项目共用；缺项说明可见；部分执行须明确选择 |
| 测试批次 | 查看本轮实际范围、进度、未执行原因 | 点击具体用例回到绑定本次运行的详情；失败项可形成新的选择复跑 |

详情采用四个页签：**结果与证据、用例正文、自动化脚本、历史结果**。有选定结果时先展示结果与媒体；无结果时说明未执行，并提供原正文、脚本准备条件。返回保留列表搜索、筛选和勾选。独立页面不默认另开浏览器窗口。

## 截图和录像如何呈现

- 首屏提供醒目的“截图与录像”大面板，与执行步骤并排，避免藏在长表单末尾。
- 三个明确入口：中文步骤回放、原始录像、步骤截图。步骤回放持续标明“非原始连续录像”；点击截图可放大并打开原图。
- 步骤旁显示原预期、实际观察、失败和未执行。点步骤只定位有可靠关联的证据；不能猜测原录像时间点。
- 用例、批次或运行切换时，结果、错误、步骤、全部媒体和脚本身份一起切换。缺素材显示缺项，不借其他运行补位。
- 播放、暂停、拖动、放大和下载是正式播放器的验收要求。原型仅绘制播放器和媒体示意，不假装可以播放真实录像。
- 清晰度和中文字幕仍需后续修复采集/编码/字幕关联；仅把播放器做大不代表原视频变清晰。

## 操作与状态

“运行已有脚本”为日常主操作，旁注明确不调用模型。生成、基于问题修订和从头重新生成放在自动化脚本页，标明调用模型，先确认范围与预算。展示“观察/开发/验证/待核对”的任务进度，不把每条 Harness 启动、自测次数作为用户主要流程；详细计数可在技术详情中查看。

执行结果、要求核查、脚本资格分开展示。执行通过但动作偏离仍显示两项事实，不自动批准候选。软件版本、用例版本、脚本包版本、批次固定关联；用例变更后不能继承旧版结果。运行失败不会自动触发模型修稿。

全项目范围不受搜索/分页缩小；跨页选择显示总数。预检列出缺脚本、版本不匹配、核查拒绝、授权或环境缺项。取消保留已完成结果与未执行项，重启不重放。页面刷新、查看视频、双击同一请求不得重复执行。
