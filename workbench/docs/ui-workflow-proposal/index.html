完整使用路径

01　项目用例库

Excel 导入 → 预览确认 → 查找用例、选择范围、查看脚本准备状态。

02　独立用例详情页

编号或标题进入独立页面，返回保留列表状态。已有结果优先展示媒体；无结果先显示用例与准备条件。

03　明确复跑

单条、选中、全项目共用预检。缺项可见，部分执行必须明确选择。

04　新批次与证据

软件、用例、脚本、运行一一绑定。从批次进入用例查看中文步骤、截图、视频和 Trace。
