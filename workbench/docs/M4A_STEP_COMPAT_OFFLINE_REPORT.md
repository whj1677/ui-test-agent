## 映射规则

规则版本：`project-case-step-title-v2`。

支持：

- 裸标记 `CASE_STEP_<正整数>`；
- 标记位于标题起始，后接一个或多个空格/Tab及非空说明；
- 标记位于标题起始，后接 `:`、`：` 或带空格的 `-`、`–`、`—` 及非空说明。

不支持任意正文包含、无分隔粘连、斜杠分隔或零/非整数编号。`CASE_STEP_1` 与 `CASE_STEP_10` 按完整 ID 区分。重复、缺失、额外步骤、非法说明标题或顺序不符都会使映射失败。

步骤覆盖与反例错误归属使用同一个映射结果。仅仅出现 `CASE_STEP_3` 不足以登记反例检出；必须从该步骤或其子步骤取得与顶层失败一致的真实 `ASSERTION_MISMATCH`。
