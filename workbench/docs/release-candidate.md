# Windows 发布候选说明

状态：PENDING_ACCEPTANCE。这是供验证的源码安装包，不是已通过正式发布验收的产品。

唯一工作台入口是 http://127.0.0.1:4322/workspace/ 。按根目录《试用说明.md》安装和启动。工作台只运行一个实例；已有实例优先复用，不静默换端口或数据目录。

包内包含三组锁定的 Node 依赖声明、工作台前后端、Harness 适配源码和安装诊断脚本。安装时需要网络下载依赖。包内没有 node_modules、原电脑的项目用例/候选/报告、历史试跑授权、已登录浏览器状态或模型凭据。首次工作区为空；模型默认关闭。

使用模型需操作者在本机完成 DSH 配置，再按启动配置模板显式绑定模型和被测环境。供应商账号与密钥由操作者自行配置，不能贴到聊天或测试报告。生成的脚本保留人工核对状态，技术运行成功不等于业务要求全部覆盖。

当前只验证同源 Cookie 身份契约；不宣称支持任意 SSO、跨域身份接口或所有业务系统。工具策略与候选静态检查不是操作系统级文件/网络隔离，不能据此安全运行任意不可信代码。真实业务、干净 Windows、普通测试人员独立操作需各自补齐证据。

带加载时长的用例按原文范围验收，不附加时间容差。当前支持引号内的加载提示和明确双边毫秒/秒范围，由执行器在对应 CASE_STEP 内观测唯一 status/aria-live 元素的一次可见周期，并将核验通过的实测值绑定到本次运行及候选文件。开始即已显示、节点替换、重复周期、缺失证据或超出范围均不能通过。候选脚本及 helper 不得自行使用时钟替代计时证据；已检出但不能明确解析的数值时间表达保留待评审状态，其他未提取的时间语义仍需人工核对。该检查覆盖 DOM 可见状态，不代表显示器像素计时或操作系统隔离，也不替代原步骤动作与业务断言的人工核对。

认证环境可显式配置 `session_termination_endpoints`，例如 `[{"path":"/api/logout","method":"POST"}]`。填写已确认会终止登录会话的精确路径及大写 HTTP 方法；模型探针和认证候选执行时拒绝这些请求，任务结束后恢复人工操作。该约束不阻止未列出的业务请求，不等于所有副作用隔离。需要测试退出或会话到期的用例应单独安排生命周期验收，不能复用要求保持登录的业务开发会话。认证生成已经携带人工完成的有效会话，自测和独立验证由执行器注入状态；模型不应读取 Cookie/storage、重新登录或自行注销清理。

归档内 candidate-manifest.json 记录每个文件的字节数及 SHA-256。可以用 Python 执行 `python workbench/scripts/package-candidate.py --verify <ZIP路径>` 复核包内字节与文件集合；核验通过只代表包完整，不表示安装、业务或发布验收通过。此清单不提供发布者数字签名。
