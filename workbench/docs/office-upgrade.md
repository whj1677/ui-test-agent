# Word / WPS 本机读取增量升级

本包仅更新 DOCX 本机读取功能，复用原安装包的 Node 和已有 Windows .NET 基础；不包含浏览器、node_modules、密钥或项目数据。

1. 保存工作台中的输入，等待任务结束，从原启动窗口按 Ctrl+C 正常停止工作台。仅关闭浏览器网页不会停止后台服务。升级器不会强行结束任务。
2. 把本升级 ZIP 解压到任意新目录，运行“升级测试工作台.exe”。不要把升级包文件直接复制到原程序目录。
3. 升级器会尝试从安装记录预填旧目录；请核对，也可点击“选择旧目录”或直接粘贴路径。安装器版本可选择包含 program 的外层目录；便携版选择包含 runtime、workbench 的程序目录。
4. 可先点击“检查目录”，再点击“升级功能”。升级前自动备份本次更改的程序文件；原依赖、密钥、配置、项目、脚本和历史结果保留。
5. 完成后用原快捷方式或启动入口打开工作台，刷新网页。在 AI 用例助手原来的输入区输入测试要求，通过“添加资料”、粘贴或拖入文件提交资料；后台先普通解析，失败后自动尝试本机 Word/WPS。
6. 企业保护文档上传后仍无法读取时，在同一个助手输入框单独粘贴原始 .docx 的完整路径（例如 D:\需求资料\需求.docx）并点击发送。助手先在本机只读提取，不调用模型；资料显示为“Word/WPS 部分读取”后，再在同一输入框输入测试范围并发送。无需另开窗口或改扩展名。

普通 DOCX、Markdown 和截图仍可使用原“添加资料”。企业保护文档经浏览器上传后可能丢失本机读取所需的保护信息，因此可在助手输入框提供原件路径，不改后缀、不去除保护。

本机读取只提取正文和表格，显示为“部分读取”；图片、页眉页脚、批注、修订和嵌入对象不算已读取。选择/读取文件不会调用模型，点击发送才会进入助手流程。文件原件保持只读。

本机需要已安装、已激活且企业策略允许自动化读取的 Word/WPS 文字版本。部分 WPS 版本未注册文字自动化接口时会明确提示，升级包不会修改企业权限或安装办公软件。两种软件同时存在时自动尝试可用组件；正在编辑的文档不会被工作台关闭。

本包已验证普通资料入口、升级、重复升级、回退及原环境保留；企业保护文档在接收电脑上的 Word/WPS 实际读取仍待验证。本机企业加密环境异常，不能据此宣称受保护文档兼容验收通过。若失败，请保留助手显示的错误码，并确认同一文件在该电脑的 Word/WPS 中能正常打开。

如需恢复旧程序，先正常停止工作台，再在同一升级器中选择原目录，点击“回退本次升级”。备份位于原程序的 workbench/.local/updates；回退不删除项目数据。如果文件在升级后又被手工修改，升级器会拒绝强制覆盖。

本升级器支持已核对程序摘要的 20261026 免激活包及对应后续助手修复版/安装器来源。版本或文件摘要不匹配时不覆盖。若提示旧程序不匹配，请保留旧目录和错误信息联系维护者，勿重复解压覆盖或删除数据。
