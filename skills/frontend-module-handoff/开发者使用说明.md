# 开发者使用

你已有 dsh。把 `frontend-module-handoff` 整个目录放到前端工程的 `.dsh/skills/` 下，在前端工程根目录启动 dsh，输入：

> 使用 frontend-module-handoff，为测试 Agent 导出“电价管理”模块，包含电价模板和电价配置。测试人员没有源码权限，分发文件不要带源码原文。

也可以仅说模块名；dsh 会找关联页面和公共组件。存在重名才需要选择模块。首次导出或前端功能更新后，使用相同说法重新导出。

完成后只把输出的 `frontend-module-handoff.json` 交给测试人员；`internal/` 留在研发侧。测试人员在工作台项目设置导入该 JSON，原有 Excel 用例继续定义测试预期。

本机 dsh 的 Skill 发现规则已通过已安装的 `dsh-skill-filesystem` 实现核对：项目优先读取 `.dsh/skills`，也支持 `.agents/skills`；如果使用 Git，项目根目录是最近的 `.git` 上级目录，没有 Git 则使用启动目录。无需安装新的 CLI 或包装启动脚本。

资料只帮助定位和等待。源码对应哪个部署版本仍须研发说明；没有版本信息会保留未知，不宣称已通过页面验证。
