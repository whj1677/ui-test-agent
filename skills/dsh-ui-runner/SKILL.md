# 独立 UI 脚本编写

输入为原确认用例、已登录测试页和授权范围。原用例决定业务预期；源码或共享资源只提供操作线索。不得改原用例、放宽断言、替换页面函数或模拟业务接口来通过。

先读 [底座接口](references/runtime-api.md)，通过 `scripts/runtime.mjs` 的 `runCase` 编写独立入口。底座负责连接、逐步证据、截图、每版源码快照、失败结果和清理；不要复制重写这些代码。每个原步骤放入对应的 `step`；每项预期用真实的 `check` 完成，计划中的输入值不能替代页面实际读回。

## 探索和复用

- 没有共享资源时，同模块只探索后续用例需要的控件。将技术操作及验证当前控件仍匹配的 guard 存入本次任务 `shared/`，不用业务用例硬编码通用库。
- 共享操作接收数据参数，不包含某条用例的预期结论。保留验证记录，通过 [共享接口](references/shared-api.md) 发布。
- 已有资料时，只读当前模块所需操作，通过 `useShared` 校验文件摘要、页面范围和当前 guard 后复用。失效只定位并修复对应操作，再发布；不重新探索整个页面，也不借另一组试验的资源。
- 共享操作与断言分开：操作完成后，当前用例仍核验实际字段、时分、档位、数值及明确错误提示。数值相等与显示格式要求遵从原用例，不自行要求尾零。

## 自测收口

必须真实执行生成脚本。可自主修复定位、语法或底座调用错误，并保存每次失败；原业务断言失败或前置缺失如实停止该用例。一个完整自测通过后结束编写，不为补充装饰性报告重复探索。

“未保存”须有有效请求观察和明确校验或关联查询证据。使用请求发起事件，不能从 ResourceTiming、旧空列表或失败查询推断未保存。短暂提示注册观察后执行动作，断言当前可见且明确的错误语义。不要把 Playwright 自己拒绝输入当成页面拒绝。

只清理本次打开的弹窗、筛选和监听，不关闭用户浏览器。没有总时长或工具次数硬限额；单次操作有诊断超时，重复尝试没有新证据时报告阻塞。结果区分 PASSED、FAILED、BLOCKED；自测通过可运行，不另设 AI 审核或人工确认步骤。
